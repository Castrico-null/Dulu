# 🌳 DULÚ - Reduce tu Huella

Un videojuego 2D de plataformas y exploración con enfoque educativo, diseñado para promover la sensibilización y el cuidado ambiental. Desarrollado como proyecto académico e investigativo en la Universidad Cooperativa de Colombia.

## 🎮 Sobre el Proyecto
**DULÚ** es una experiencia interactiva construida en **Unreal Engine** utilizando el sistema de programación visual Blueprints. A través de sus mecánicas 2D y diseño de niveles, el juego busca educar a los jugadores sobre la importancia de reducir la huella ambiental y proteger los entornos naturales.

### ✨ Características Principales
* **Mecánicas de Plataformas 2D:** Movimiento fluido, interacción con el entorno y colisiones precisas.
* **Arte y Sprites Personalizados:** Animaciones cuadro por cuadro integradas mediante TileMaps y Flipbooks.
* **Enfoque Educativo:** Elementos interactivos en el entorno orientados a la concientización ambiental.
* **Interfaz de Usuario:** Menús interactivos con transición fluida entre la navegación del cursor y los controles del personaje.

## 🛠️ Tecnologías Utilizadas
* **Motor:** Unreal Engine (Lógica en Blueprints).
* **Control de Versiones:** Git y **Git LFS** (Large File Storage) para la gestión segura de assets pesados (`.uasset`, `.umap`).

## 🚀 Cómo clonar el repositorio

Debido a que el proyecto utiliza assets nativos de Unreal Engine, es **obligatorio** tener instalado Git LFS para que los mapas y las texturas se descarguen correctamente.

### Instalación
Abre tu terminal y ejecuta:
git clone https://github.com/Castrico-null/Dulu.git
cd Dulu
git lfs pull

## 📦 Ejecución (Versión PC)
El juego está optimizado para su ejecución en sistemas Windows. 
Para jugar la versión compilada, simplemente ejecuta el archivo `Dulu.exe` que se genere tras el empaquetado del proyecto.
